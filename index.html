一个 API，接入所有模型站点

Hoshimi 把 Cline、TRAE、ZCode、Qoder、MiniMax、Gemini、CodeBuddy、Kilo 等免费模型站点，以及云服务与本地模型，汇聚到同一个 API 和网页界面：Chat Completions、Responses 与 Anthropic Messages 三种协议任选，账号登录、续期与轮换自动完成，还带一个能动手的 Playground。

WORKFLOW

从安装到第一次调用

四步走完整个流程，每一步在网页界面和命令行中都有对应做法。

  1. 01

    安装 Hoshimi

    需要 Python 3.10 或更新版本：pip install hoshimi。网页界面已打包在内，无需构建前端。

  2. 02

    启动服务

    运行 hoshimi serve，打开 http://127.0.0.1:10600。OpenCode Zen 与 Kilo 的匿名入口默认开启，无需配置即可试用。

  3. 03

    添加渠道

    在 渠道 页面填入密钥或登录站点账号；也可以用 hoshimi login 在命令行中完成。

  4. 04

    接入客户端

    把客户端的 Base URL 指向 http://127.0.0.1:10600/v1，用 Hoshimi 列出的模型 ID 发起请求。

WHY HOSHIMI

站点各不相同，用法始终一致

账号、协议、配额与故障的差异交给 Hoshimi 处理，你只需要一个地址和一个密钥。

  • 三种协议，一个地址

    任一客户端协议都能调用任一渠道的模型：流式输出、推理内容、工具调用与图片在协议之间转换。

  • 开箱即用

    安装后无需任何配置文件就能对话：匿名入口默认开启，之后再按需添加自己的账号。

  • 账号自动维护

    令牌自动续期，失败时在账号间轮换重试，记住不可用的模型，每日签到领取额度。

  • 默认安全

    默认只监听本机；工具访问密钥与模型 API 密钥相互独立，并可按网段、主机名与来源限制访问。

  • 能动手的 Playground

    内置读取文件、编辑补丁、命令行、后台命令、网页搜索与抓取六种工具，三种审批模式，回复进行中也能补充要求。
