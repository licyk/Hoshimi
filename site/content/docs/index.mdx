Hoshimi 是一个用 Python 编写的模型网关。它把免费模型站点（Cline、TRAE、ZCode、Qoder、MiniMax、Gemini、CodeBuddy、Kilo、OpenCode Zen 等）、云服务（Azure、Cloudflare、Vertex、Bedrock、NVIDIA NIM 等）和本地或自建的 OpenAI 兼容服务接到**同一个本地服务器**后面：客户端只需要一个 Base URL 和一份模型目录，就能通过 Chat Completions、Responses 或 Anthropic Messages 调用其中任何一个模型；一个多语言的 Web UI 用来管理渠道和账户、浏览模型、聊天和查看用量。

安装后执行 `hoshimi serve`，打开 `http://127.0.0.1:10600` 即可使用。OpenCode Zen 和 Kilo 的匿名入口默认启用，不需要账户，也不需要配置文件。

## 能做什么

| 功能 | 说明 | 详见 |
| --- | --- | --- |
| 统一接口 | 在 `/v1` 下提供 Chat Completions、Responses、Anthropic Messages 与 Token 计数，以及模型列表 | [接入客户端](/docs/clients) |
| 渠道与账户 | API Key、浏览器或设备码登录、凭据自动续期、多账户轮换、余额与每日签到 | [渠道](/docs/guide-channels)、[渠道概念](/docs/providers) |
| 模型目录 | 每个模型的能力（推理、视觉、工具调用）、思考强度选项和可用性探测 | [模型](/docs/guide-models)、[模型行为](/docs/advanced-models) |
| 实时用量 | 进行中的调用、Token 与缓存明细、首字延迟和生成速度，可按小时查看任意一天，保存在本地 SQLite 数据库中 | [用量](/docs/guide-usage) |
| Playground | 在浏览器里和任意模型聊天，可选内置工具（读写文件、运行命令、搜索网页），执行前征求同意 | [Playground](/docs/guide-playground)、[Playground 工具](/docs/guide-agent) |
| 安全 | 管理界面与模型接口各自独立的密钥，允许的网段、主机名与来源 | [安全](/docs/config-security) |
