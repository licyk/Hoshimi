本节逐页讲解 Hoshimi 的 Web 界面。启动 `hoshimi serve` 后，在浏览器中打开 `http://127.0.0.1:10600`（端口被占用时以服务器打印的地址为准）。还没有安装的话，先看[快速开始](/docs/quick-start)；第一次打开界面时会看到什么，见[首次启动](/docs/first-run)。

在 **渠道** 和 **设置** 中做的修改都写入数据目录中的 `config.json`（外观和语言等浏览器偏好除外），并立即作用于正在运行的网关，不需要重启（监听地址和端口除外）。大部分操作也可以用[命令行](/docs/cli)或[管理 API](/docs/api-management) 完成。

## 导航

窗口较宽时导航栏在左侧，窄窗口（如手机）时移到底部。**设置** 固定在导航栏最下方。

| 页面 | 用来做什么 |
| --- | --- |
| **概览** | 今天的用量、可复制的接口地址、已启用的渠道、版本与默认模型 |
| **模型** | 所有可调用的模型：搜索、能力、上下文长度、可用性探测，并可直接在 Playground 中试用 |
| **渠道** | 每个提供商（免费站点、云服务、本地服务）的账号：登录、添加密钥、续期、签到、额度和网络线路 |
| **用量** | Token 用量、缓存命中、首字延迟和速度的图表，按模型/提供方/账户/接口的明细，以及每一次调用的记录 |
| **Playground** | 在浏览器中直接和任意模型对话；开启工具后还能读写文件、运行命令、搜索网页 |
| **设置** | 语言、默认模型、Playground 与工具、监听地址和密钥、访问限制、全局网络、定时任务、外观 |

有渠道需要处理（需要重新登录、令牌过期、账户被暂停轮换、额度快用完）时，**渠道** 图标上会显示需要处理的渠道数量。

每个页面在切换后保持原来的状态和滚动位置，再次点导航会回到你离开时的位置。部分状态记在地址里，刷新或把链接发给别人时会打开同一个视图：

| 地址 | 打开 |
| --- | --- |
| `#/channels/kilo` | **渠道** 页中的 Kilo 渠道 |
| `#/usage?range=30d` | **用量** 页的 **30 天** 范围 |
| `#/usage?range=day&date=2026-10-20` | **用量** 页中的某一天 |
| `#/settings?tab=access` | **设置** 的 **访问** 标签页 |

## 顶栏

右上角有两个按钮：

- **实时活动**：没有调用时是一个活动图标；有调用正在进行时变成转圈的图标并显示数量（**N 个调用进行中**）。点开是实时活动面板：
  - 顶部是连接状态（**实时**、**正在重连…**、**离线**）和今天的 **今日 Token**、**调用次数**、**缓存命中**。
  - **正在进行（N）** 为每个调用显示一张卡片：模型、提供方 / 账户（还在选账户时显示 **正在选择账户…**）、接口、推理强度、尝试过的账户数，一条 **等待中**、**思考中**、**回答中** 的进度条，以及 **首字延迟**、**输出 Token**（在站点报告最终数量之前是按已输出文本的估算，带 ≈）和 **tok/s**。
  - **刚刚完成** 列出最近 10 个调用，标明 **已回答** 或 **失败**。
  - **打开用量** 跳到 **用量** 页。
- **主题**：在浅色、深色和跟随系统之间轮流切换。更多外观选项在 **设置 › 外观**。

实时活动、**概览** 的今日数字和 **用量** 页共用一条到服务器的实时连接（`/api/v1/stats/live`）。连接断开后会自动重连，重连时取得一份新的快照，不会漏掉中间的变化。

## 访问密钥

服务器设置了工具访问密钥（`server.access_token`）时，打开界面会弹出 **请输入工具访问密钥**。输入密钥点 **登录**，界面会先向服务器验证；验证通过后，密钥保存在这个浏览器的 localStorage 中，之后不再询问。密钥错误时提示 **工具访问密钥不正确。**，原来保存的密钥不会被覆盖。

在 **设置 › 访问** 中修改或清除密钥后，当前浏览器会自动换成新密钥；其他浏览器需要重新登录。Playground 走的是管理接口，只需要工具访问密钥，不需要模型 API 密钥。两种密钥的区别见[访问控制与安全](/docs/config-security)。

## 语言与外观

界面默认跟随系统语言，支持 English、简体中文和日本語，可以在 **设置 › 常规 › 语言** 中固定一种。主题、主题色、对比度和动画在 **设置 › 外观** 中设置。这些都是浏览器端的偏好，保存在当前浏览器中，不写入服务器的配置文件。

## 模型目录的加载

**模型**、**Playground** 和 **设置** 中的模型选择器共用同一份模型目录。目录以流的方式加载：先显示缓存中的模型，各提供商再分别补上自己的结果，加载中显示 **正在加载供应商：已完成/总数**。某个提供商失败或超时（20 秒）时会列出它和原因，并保留已有的模型，点 **重试** 再加载一次。详见[模型](/docs/guide-models)。
